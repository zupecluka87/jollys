JOLLY-S PLUG & PLAY STRAN

1. Celotno mapo naloži na GitHub.
2. Na Netlify naredi nov site iz GitHub repozitorija.
3. V Netlify vklopi:
   Site configuration > Identity > Enable Identity
   Identity > Services > Git Gateway > Enable Git Gateway
4. Odpri:
   https://tvoja-domena.netlify.app/admin
5. Povabi svoj email v Identity in se prijavi.
6. V adminu urejaš:
   - logo
   - hero sliko
   - tekste
   - projekte
   - galerije
   - slike

VELIKOSTI SLIK:
heroImage: 3200 x 1900 px
logo: 512 x 512 px PNG
cover: 1600 x 1600 px
detail: 1200 x 1200 px
gallery: 1200 x 1200 px
